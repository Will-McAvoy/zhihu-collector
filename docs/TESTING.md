## 已知限制

- 个别浏览器初始化或退出仍可能超时。程序按有限等待回收本会话进程；重试成功不能抹去第一次超时。
- 一次 EXE 初次启动约 58 秒，超出原脚本 22 秒等待；随后保留原等待时限，用新空输出目录重跑成功。首次偏慢的底层原因未确定。
- Windows 文件占用可能使缓存暂留。程序保留归属记录，下次启动补清；最终复查安全清理后受检归属记录为 0，不代表第一次退出就全部清零。
- 网页参考数量与实际可见列表可能不同。程序保留差额与未确认状态；不能统一归因于网站，也不伪造缺失回答。
- 私密收藏夹真实验收、两个物理磁盘和连续数天运行尚未完成；本轮未完成整个大型收藏夹的全量归档。
- 登录、验证码、网站访问权限和频控影响真实采集；不包含自动破解或绕过机制。

本机原始测试在隔离目录进行。日常数据库、设置与预设保持不变；仅按用户扫码授权刷新登录状态，旧文件已备份。个人数据和历史记录不属于开源发布范围。
